Check the receiving format

Before choosing a converter, decide what the recipient or application accepts. Image-based PDF pages do not become editable text. CSV values remain strings, even when they look numeric. Encoded values must use the variant expected by the receiving system. Each tool page includes a sample and explains the limits of its output.

The controls above narrow the list by category or task. With JavaScript disabled, all tool cards remain available. Public tools currently have no usage fee; temporary email has service and abuse-prevention limits.
