UUID Generator

Create one or many RFC 4122 version 4 UUIDs using the browser’s cryptographically secure random-number generator.

Generate UUIDs

How it works
  • Choose a count from 1 to 100.
  • Each UUID uses secure random bytes and the required version and variant bits.
  • Copy the list or download it as a plain-text file.
Common uses
  • Creating database identifiers.
  • Preparing unique IDs for test fixtures.
  • Generating correlation IDs for development.
Your input stays in this browser. Nothing entered into this tool is sent to the Anvil Tools server.
Frequently asked questions
Are these UUIDs guaranteed never to collide?
No finite random identifier can offer an absolute guarantee, but version 4 UUIDs have 122 random bits, making accidental collisions extraordinarily unlikely when generated correctly.
Are they generated securely?
Yes. The tool uses crypto.randomUUID when available and a crypto.getRandomValues fallback with RFC 4122 version and variant bits.
A practical walkthrough
  1. Generate a batch of UUIDs for test records, then copy the values into your development dataset.
  2. Preserve the full identifier, including all hexadecimal groups, when moving it between systems.
  3. Copy the generated UUIDs or download the text file. Enforce uniqueness in your application when storing identifiers.
Tips for a reliable result
Random UUIDs have an extremely low collision probability, but a database should still enforce uniqueness. Identifiers are not passwords or access controls.

Working with your results
Can a UUID prove that someone owns a record?
No. An identifier names a record; authorization must still be checked by the application. Do not treat possession of a UUID as permission to access private data.
Do I still need a unique constraint?
Yes. Random version 4 UUID collisions are extremely unlikely, but storage should enforce uniqueness and handle conflicts rather than assuming they are impossible.
