PDF Merge

Add two or more PDF files and they'll be stitched together into one document, in the order shown in the list. Everything happens in your browser, so your files are never uploaded to a server.

Use readable, unencrypted PDFs. Check forms, signatures, and bookmarks in the output; their interactive behavior is not guaranteed.

    How it works

    • Choose or drag in the PDF files you want to combine.
    • Use Move up, Move down, or Remove to arrange the file list. All pages within each PDF keep their original order.
    • Click merge, and the combined file downloads straight to your device.

    Common uses

    • Combining several scanned pages into one document to send or print.
    • Putting together a multi-part report or application from separate PDF sections.
    • Merging an invoice and its attachments into a single file for record-keeping.
    Your privacy matters here: check the FAQ below for exactly what happens to anything you enter into this tool.

    Check page order

    Add two unencrypted PDF documents, inspect their order in the list, and remove any unwanted file before merging. Open the downloaded PDF to confirm every page is present. Corrupt or password-protected PDFs may not be supported.

    A practical walkthrough

    1. Combine a cover letter and supporting documents into one PDF. Arrange the files in the order the recipient should read them.
    2. Open the downloaded document and check the page order, rotation, and total page count.
    3. Use Merge and download, then open the PDF and check its page order. Keep the source documents.

    Tips for a reliable result

    Encrypted, damaged, or unusually large files may fail. Try a smaller batch and retain the original documents.

    Questions and troubleshooting

    Is there a limit to how many files I can merge?

    There's no fixed limit, but very large combined files take longer to process since everything happens on your own device.

    Can I merge password-protected PDFs?

    No. Remove the password from a PDF first using your PDF reader, then merge it here.

    Does merging reduce file quality?

    No. Pages are copied as-is, so the content and quality of each original file is preserved.

    When a PDF cannot be merged

    Check that every selected file is a readable, unencrypted PDF. Try each source in a PDF reader to identify a damaged file. If a large batch exhausts browser memory, use smaller batches and recheck page order. This tool has no password-unlocking control.

    Will merging make scanned pages searchable?

    No. Merging copies pages into a combined document; it does not run optical character recognition. An image-only scan remains image-only.

    How do I check the final document?

    Open the downloaded PDF, check its page count and order, and inspect important pages. Forms, signatures, bookmarks, and other document features may not survive a merge as you expect.
