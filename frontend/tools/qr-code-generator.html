QR Code Generator

Paste in a web address, a piece of text, or contact details, and get back a QR code that any phone camera can scan. The code is generated entirely in your browser and can be downloaded straight away as a PNG image.

Create a QR code

How it works

  • Type or paste your link or text into the box.
  • Click generate, and a QR code appears immediately.
  • Download the code as a PNG to print or share.

Common uses

  • Adding a scannable link to a flyer, menu, or business card.
  • Sharing a Wi-Fi password or contact card without typing it out.
  • Linking a printed document to an online form or page.
Your privacy matters here: check the FAQ below for exactly what happens to anything you enter into this tool.

Frequently asked questions

Is there a limit on how much text I can encode?

QR codes can hold a few thousand characters, but shorter input produces a simpler, easier-to-scan code. Stick to short links or messages where possible.

Does the QR code expire?

No. Once generated and downloaded, it's a static image that works for as long as the content it points to (like a web page) stays available.

Can I change the color or add a logo?

This tool generates a standard black-and-white code for maximum scan reliability. Color and logo customization is not currently supported.

Test before printing

Use a complete HTTPS address, download the image, and scan it with another device. Keep a clear border around the code and avoid shrinking it until the small squares merge.

A practical walkthrough

  1. Enter a complete website address, generate a code, and download it for a flyer or document.
  2. Scan the downloaded code with a phone before printing. Confirm it opens the exact destination you intended.
  3. Copy or download the result using the controls above. Keep your original input until you have checked the output in its destination.

Tips for a reliable result

Keep a clear margin and strong contrast around the code. Long input makes a denser code that may need a larger printed size.

Start with a small example to confirm the settings, then repeat with your full input. If you change an option, run the tool again and review the new output before replacing an earlier result.

Working with your results

Can I change the destination after downloading a code?

The generated code stores the text you supplied. To change it, generate a new code. If you encode a URL you control, you may change what that URL serves separately.

What should I test before printing?

Scan the actual downloaded image at its intended printed size. Check the destination, preserve a blank margin, and avoid placing a logo or decoration over the code.
