Check the scale and the offset

Length and mass conversions multiply by a ratio. Temperature also uses an offset. The displayed result rounds length and mass to six decimals and temperature to three; keep the original precision when performing further calculations.

How it works

  • Choose a category: length, weight, or temperature.
  • Enter a value and pick the units to convert from and to.
  • The result updates immediately as you change any field.

Common uses

  • Converting a recipe's weights between metric and imperial units.
  • Checking a package's dimensions in the units your shipping carrier requires.
  • Converting a weather forecast's temperature to a scale you're more used to.

Check units and precision

Convert 100 Celsius to Fahrenheit to get 212. Unit conversions use standard factors and rounded display values. This is not a currency converter or a substitute for precision engineering calculations.

A practical walkthrough

  1. Choose length and convert 1 kilometer to meters; the expected result is 1000 meters.
  2. Check the conversion category and both unit labels before using the number in another document.
  3. Read the converted value and its units above. Select and copy the result manually; this tool has no download button.

Tips for a reliable result

Temperature uses an offset as well as a scale. Display rounding can make a round-trip conversion differ slightly from the original value.

Questions and troubleshooting

Which units are supported?

Length covers meters, kilometers, centimeters, millimeters, miles, yards, feet, and inches. Weight covers kilograms, grams, milligrams, pounds, ounces, and tonnes. Temperature covers Celsius, Fahrenheit, and Kelvin.

How precise are the conversions?

Results are rounded to a sensible number of decimal places for readability, using standard conversion factors.

Can more unit categories be added?

This tool covers the most commonly requested categories; additional ones like volume or area can be added over time.

When a conversion has the wrong scale

Enter a finite numeric value and confirm both units and the measurement category. Zero is valid; a blank input is not. Temperature conversion includes an offset, unlike a simple length ratio. Check precision and rounding against the intended use.

Should I round the input before converting?

Keep the available input precision and round the final result for your use case. Repeated rounding can introduce avoidable differences.

Can I convert between unrelated measurement types?

Choose units in the same supported category. Length, weight, and temperature measure different quantities and cannot be converted into each other by this tool.
