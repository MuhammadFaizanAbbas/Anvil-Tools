How it works
  • Choose seconds or milliseconds when entering a Unix value.

Common uses

  • Comparing local time with UTC during incident analysis.
Your input stays in this browser. Nothing entered into this tool is sent to the Anvil Tools server.
Frequently asked questions
What is Unix time?
Unix time counts elapsed seconds from 1970-01-01 00:00:00 UTC. Many JavaScript APIs use milliseconds instead.
How are time zones handled?
A Unix timestamp identifies one instant. The tool shows that instant in UTC and your browser’s local zone. Date input is interpreted according to the option you choose.
