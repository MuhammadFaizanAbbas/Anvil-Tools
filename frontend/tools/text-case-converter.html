How it works

  • Paste text and choose the target case.
  • Prose modes preserve punctuation and spacing.
  • Identifier modes extract letters and numbers, then join normalized words.

Common uses

  • Preparing headings and labels.
  • Creating variable or CSS class names.
  • Normalizing filenames and URL slugs.
Your input stays in this browser. Nothing entered into this tool is sent to the Anvil Tools server.

A practical walkthrough

  1. Paste a heading or identifier, select a case style, and inspect the converted result before copying it.
  2. Check brand names, acronyms, and words with special capitalization manually after conversion.
  3. Use Copy to copy the converted text. Review acronyms, names and punctuation before replacing the original.

Tips for a reliable result

Automatic case conversion does not understand every editorial convention. Keep a copy of the original when changing a large passage.

Questions and troubleshooting

How does title case handle small words?

This tool capitalizes each word consistently. Editorial title-case rules differ by style guide, so review titles that contain articles, conjunctions, or prepositions.

Does it support non-English text?

Uppercase, lowercase, title, and sentence modes use Unicode-aware browser casing. Identifier modes recognize Unicode letters and numbers.

When converted text needs corrections

Choose the intended transformation and review names, acronyms, and language-specific capitalization. Keep the original text for comparison. Copy failures can be handled by selecting the displayed output manually; capitalization rules do not replace editorial review.

Will it preserve brand names and acronyms?

Automatic case rules can change deliberate capitalization. Review names, acronyms, and headings manually after converting.

Is changing case a translation?

No. The tool changes the presentation of the text; it does not translate meaning or correct grammar. Keep the original when applying changes to a long passage.
