    Understand image size and page size

    The converter uses image width and height as PDF page dimensions in points. It embeds each image as a page without OCR. A pixel count is not a promise of a particular print size or resolution.

    Input or checkExpected result or decision

    How it works

    • Choose or drag in your JPG, PNG, or WebP images. Use Move up, Move down, or Remove to set the page order.
    • Each image becomes one page in the resulting PDF, sized to match the image.
    • Click convert to build and download the finished PDF.

    Common uses

    • Turning phone photos of a signed document into a single PDF to email.
    • Bundling receipt photos into one file for an expense report.
    • Creating a simple PDF portfolio from a set of images.
    Your privacy matters here: check the FAQ below for exactly what happens to anything you enter into this tool.

    Prepare images for a document

    PNG, JPEG and WebP images can become separate PDF pages. Each page uses the image dimensions. For consistent page sizes, resize the source images first. Very large images can exceed your browser memory.

    A practical walkthrough

    1. Select photographs of a multi-page document in reading order and convert them into a single PDF.
    2. Check that every page is upright and that small text remains readable at normal zoom.
    3. Use the conversion button to download the PDF, then open it and inspect every image page.

    Tips for a reliable result

    This creates image-based pages, not searchable OCR text. Crop and rotate your source images first for a cleaner document.

    Questions and troubleshooting

    What image formats are supported?

    JPG, PNG, and WebP. If your browser cannot decode an image, export a working copy as PNG or JPEG and retry.

    Can I control the page order?

    Yes. Use Move up, Move down, or Remove in the selected-image list before converting. Each remaining image becomes one PDF page in that order.

    Will the images be resized?

    Each page is sized to match its image, so nothing is cropped or stretched.

    When an image cannot be converted

    Open the source in an image viewer, then export a working copy as PNG or JPEG if the browser cannot decode its format. Retry with smaller images if memory is limited. Use Move up and Move down to arrange the selected images before converting. Crop and rotate source images in an image editor first.

    Why does the PDF contain large or differently sized pages?

    Pages follow the dimensions of the source images. Prepare consistently sized, upright images first if the final document needs a uniform appearance.

    Does the converter recognize handwriting?

    No. It places images into PDF pages without recognizing text. Keep the images readable and use a separate OCR workflow if searchable text is required.
