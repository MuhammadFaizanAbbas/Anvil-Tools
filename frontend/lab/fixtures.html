How to use the library

  1. Download the fixture without changing it.
  2. Confirm its SHA-256 hash when exact-byte reproduction matters.
  3. Run it through the named tool and compare the observed output with the expected result.
  4. Record the browser, date, and any difference instead of replacing the fixture with production data.

Handling rules

  • Keep fixtures separate from production records.
  • Never replace sample tokens with live credentials.
  • Review downloaded PDFs and images before forwarding them.
  • Use only systems you own or are authorized to test.
