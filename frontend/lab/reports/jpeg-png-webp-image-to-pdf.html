JPEG, PNG, and WebP conversion evidence

How do three encodings of the same 640 × 400 synthetic image differ before and after Image to PDF conversion?

Written by: VelloxTech Editorial Team

Last tested: October 6, 2026

Report an error or suggest a correction

Test environment

Chrome 154.0.8037.97 and Edge 154.0.4258.53; 1100 × 850 viewport; output independently reopened with pypdf 6.1.1.

Fixture and expected result

Each conversion creates one 640 × 400-point page with one 640 × 400 embedded image. PNG and WebP retain an alpha soft mask; flattened JPEG does not.

Reproduction steps

  1. Download the three source images.
  2. Convert each separately with Image to PDF.
  3. Open the PDF and compare page dimensions and transparency behavior.
  4. Compare your hash only with the recorded artifact from the same run; fresh PDF bytes may differ.

Observed result

Six downloads—three formats in each browser—matched the expected page dimensions and image dimensions. The recorded source sizes are 16,987-byte JPEG, 18,067-byte PNG, and 8,250-byte lossless WebP.

What this test does not establish

This single illustration does not rank formats for every photograph, color profile, encoder, or printer. The PDF contains an image, not searchable text.
