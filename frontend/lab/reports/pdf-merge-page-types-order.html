PDF merge order, page size, and text-layer check

Does merging a one-page cover, two-page application, and one support page preserve whole-file order and mixed page dimensions?

Written by: VelloxTech Editorial Team

Last tested: October 5, 2026

Report an error or suggest a correction

Test environment

Browser PDF Merge run using synthetic PDFs; output reopened with an independent PDF parser.

Fixture and expected result

Four pages in cover, application page 1, application page 2, support order; dimensions 420 × 594, 400 × 600, 401 × 601, and 360 × 480 points.

Reproduction steps

  1. Download the three source PDFs.
  2. Add them to PDF Merge and arrange cover, application, support.
  3. Merge and compare the download with the recorded four-page fixture.
  4. Inspect forms, signatures, bookmarks, links, and accessibility separately when they matter.

Observed result

The recorded merged fixture contains four pages in the expected whole-file order and retains the intentionally different page sizes. The merge does not standardize layout or run OCR.

Downloadable evidence

  • cover.pdf
  • application.pdf
  • support.pdf
  • merged-example.pdf

The fixture library publishes SHA-256 hashes for exact-byte verification.

What this test does not establish

The fixture uses simple unencrypted PDFs. It does not prove preservation of digital signatures, interactive forms, attachments, bookmarks, tags, or encrypted files.
