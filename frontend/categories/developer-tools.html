Choosing between developer tools

Base64 Encoder & Decoder

Convert text to Base64 and back, entirely in your browser. Preserve padding and character case when copying encoded data between systems.

CSV to JSON Converter

Convert quoted CSV data into JSON arrays or objects locally. Inspect the generated objects and make sure every row has the same number of columns before using the JSON.

Hash Generator

Generate SHA-256, SHA-384, or SHA-512 hashes from UTF-8 text. Use the same algorithm and exact input bytes when comparing two digests. Spaces and line endings are part of the input.

JSON Formatter & Validator

Pretty-print, minify, and validate JSON directly in your browser. Check nesting, property names, and data types before copying the result into a configuration file.

JWT Decoder

Inspect a JWT header and payload without uploading the token. Read issuer, audience, and expiry together. A readable payload alone does not prove that the token is authentic.

Unix Timestamp Converter

Convert Unix seconds or milliseconds to readable local and UTC dates. Look at the UTC result as well as your local time; they represent the same instant with different timezone displays.

URL Encoder & Decoder

Encode text for a URL or decode percent-encoded values safely. Choose component mode for a single value and full-URL mode when separators such as slashes must be preserved.

User Agent Generator

Grab realistic browser and bot user-agent strings for testing how your site responds. Test both recognized and unexpected strings so your application has a useful fallback.

Before you start

Open a tool to find its instructions, example workflow, and FAQs. Test a small input first, check the result, and follow the suggested next tools when your task needs another step. Save any output you need before closing the tab.
