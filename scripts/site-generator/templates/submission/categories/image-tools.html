Automatic removal or manual editing?

Use automatic removal when the subject has a reasonably clear boundary and you can inspect the result. A manual editor gives more control over hair, translucent material, reflections, and product shadows. This site provides automatic removal and a PNG download; it does not provide a brush, edge-refinement panel, or layer editor.

Source or taskUseful next step
A clear product silhouetteTry Background Remover, then inspect small holes, handles, and fine edges.
Hair, glass, or a subject close in color to the backgroundExpect missed or retained pixels. Improve the source or finish the selection in a manual editor.
A marketplace or print deliveryCheck the destination's dimensions, background requirements, and file format after editing.

What the example actually shows

The background-removal guide explains how to inspect transparency, distinguish edge errors from shadows, and prepare the final export. You can also download the original sample and compare your result.

Formats and first-use costs

The tool accepts PNG, JPEG, and WebP and downloads a transparent PNG. The first run loads approximately 52 MB of model resources, so the initial wait can be longer than later runs. Your image is processed in the browser; model and page requests still use a network connection. A smaller copy can help when device memory is limited. Keep the original until the output has been checked.

If the prepared image needs to join a document, use Image to PDF. For a surrounding page or presentation, compare text against its actual background rather than relying only on a generated palette.
