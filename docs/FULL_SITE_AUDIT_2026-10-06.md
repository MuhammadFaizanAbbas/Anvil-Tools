## Findings fixed

- Local PDF and QR bundles replace blocking CDN dependencies; PDF scripts defer loading. Before-release mobile Lighthouse performance was 72 for PDF Merge and 84 for Image to PDF. Compare the live after report before claiming an improvement.
- Successful blogs omit retry and one-page navigation text; failures expose a retry and multi-page lists use ordinary crawlable links.
- Brand/social metadata, publisher/editorial disclosure and conditional Google advertising privacy choices are current.
- Four original experiment articles include actual screenshots, fixed fixtures, observed results and independently reopened Chrome/Edge PDF outputs.
- Permanent cPanel/Vercel rules consolidate the review domain on `https://nevco.online`, preserving cPanel paths and queries.
- Public database backup privileges, media bucket privacy, API loading deadlines, blocked-storage handling, transient PHP failures and stale browser assets are addressed as described above.

## Account and physical checks

1. **nevco.online publication:** its PHP/LiteSpeed cPanel host is separate from the GitHub/Vercel deploys. An existing cPanel/SSH/SFTP deployment connection is required. The complete `frontend.zip` includes updated administrator files and local PDF/QR bundles. Existing model files and seller records must be preserved. Do not describe nevco.online as updated until the after check passes.
2. **Supabase Auth:** the security advisor reports leaked-password protection disabled. The connected database tools cannot update this Auth setting. Enable it in the project's Auth settings if available on the current plan, then recheck the advisor. See [Supabase password security](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).
3. **AdSense activation:** advertising is disabled. Before activation, verify the actual publisher/seller records, provider list, placement and applicable consent configuration. Google requires a certified CMP for the covered personalized-ad regions; disabling personalization does not automatically remove consent obligations. No account review, traffic acquisition practices or future ad layout is certified here.
4. **External delivery:** contact UI/SMTP persistence and recovery use synthetic fixtures. Receipt arrival, sender mailbox delivery and support replies require a controlled mailbox test; no external messages were sent.
5. **Devices and accessibility:** Chrome/Edge and phone sizes are emulated on this workstation. Physical iOS/Android, assistive-technology review, real print scans and field Core Web Vitals are separate checks. Automated accessibility results alone do not prove full accessibility.
6. **Google indexing:** site ownership, Search Console submission/reindexing, cache refresh and the final AdSense decision require the owner's account.
